# Γραμματοσειρές για τις κάρτες των social

Δύο αρχεία TTF, κατεβασμένα μία φορά από τις Google Fonts:

- `SourceSerif4-SemiBold.ttf` — οι τίτλοι
- `Commissioner-SemiBold.ttf` — οι μικρές ετικέτες (ΚΕΦΑΛΑΙΑ)

Είναι οι **ίδιες** γραμματοσειρές με το site. Το `public/fonts/` τις
έχει σε μορφή woff2, που τη διαβάζει ο browser αλλά **όχι** ο
σχεδιαστής εικόνας του `make-cards.js`. Γι' αυτό υπάρχουν δύο φορές.

Άδεια: SIL Open Font License 1.1 — ελεύθερη χρήση, και σε εμπορικά.

Αν χρειαστεί να ξανακατέβουν:

```
https://fonts.googleapis.com/css2?family=Source+Serif+4:wght@600&family=Commissioner:wght@600&subset=greek
```

με `User-Agent: Mozilla/4.0`, ώστε η Google να απαντήσει με TTF αντί
για woff2. Μέσα στην απάντηση είναι οι διευθύνσεις των αρχείων.
